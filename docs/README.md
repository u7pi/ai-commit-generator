## Documentation conventions

- Keep the project README focused on the overview, installation, and quick start; place detailed guides in this directory.
- Use lowercase, hyphen-separated filenames for guides and one top-level heading per document.
- Use relative links for repository files, with a link back to this index in each guide.
- Keep settings, command names, and examples consistent with the extension; update both changelogs when preparing a release.
